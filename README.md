# Línea de Envasado 3D — ExpoEducativa Tecnicatura

Simulador web 3D interactivo de una línea de envasado de polvos en flowpack,
controlable en tiempo real desde un ESP32 físico.

**Proyecto:** PA-29 — vinculado a PA-19 Tecnicatura (UNaP)

## Stack
- Three.js (3D)
- Node.js + WebSocket + MQTT (servidor)
- ESP32 + Arduino IDE (hardware)
- HiveMQ Cloud (broker MQTT)
